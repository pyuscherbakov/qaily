## Проверки без записи

Проверяй отдельно и сообщай статус ok, error или not_checked и причину, не раскрывая значения секретов, заголовки, query URL или содержимое ошибок:

1. **Зависимости:** наличие `uv`, `node`, `git`; отдельно доступность browser MCP и его ресурсов. Недоступность необязательного browser не блокирует review-testcase.
2. **Конфигурация и секреты:** выполни `uv run -q --script "<installedPath>/bin/qaily_launch.py" check`, подставив разрешённый путь. Это проверка здоровья токенов с кодом 0/1; она не проверяет MCP. Context7 необязателен. Отсутствие keyring / Secret Service — объясни возможность задать необходимые `QAILY_<NAME>` пользователем вне чата. Jam при необходимости предложи авторизовать через OAuth клиента. Не запускай `headers`: его вывод содержит авторизацию.
3. **HTTP:** 200 подтверждает только ответ HTTP. 401 может означать ошибку авторизации; 403 также может означать недостаток прав. Сетевая ошибка может означать VPN, регион или недоступность сервиса, а не неверный токен. По данным пользователя официальный TestOps endpoint доступен только из РФ.
4. **MCP:** через доступные инструменты клиента, без самописного MCP-клиента, отдельно проверь initialize, каталог и безопасное чтение без изменения данных. Если инструменты или доступ отсутствуют, укажи not_checked и причину. Проверь доступность каталога вложений только чтением; отказ sandbox сообщи без запроса расширения прав и без обхода ограничений.
5. **Политика:** отдельно проверь статическую конфигурацию и наблюдаемое применение через разрешённые средства клиента. Наличие конфигурации не доказывает enforcement. Не выполняй запись и не обходи подтверждения для проверки.

В Codex top-level `QAILY_TESTOPS_AUTHORIZATION` содержит полный заголовок `Api-Token ...`, задаётся пользователем в окружении процесса отдельно от raw `QAILY_ALLURE` и keyring; автоматической конвертации нет. Не проси и не печатай значение. Для уже применённого config проверь актуальность пути `http_headers_helper`, если он настроен, без вывода пути или содержимого файла; если TOML parser недоступен (например Python 3.10), сообщи not_checked. Изменения секретов могут требовать перезапуска клиента. Runtime policy, работа реальных сервисов и дочерних процессов не подтверждаются статической проверкой.
