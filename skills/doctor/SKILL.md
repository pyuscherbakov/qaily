# Диагностика qaily

Выполни одной командой:

```bash
uv run -q --script "${CLAUDE_PLUGIN_ROOT}/bin/qaily_launch.py" check
```

Каждая строка вывода — один токен: `<имя>: <источник> — <результат>`. Источник `env` —
переменная `QAILY_<ИМЯ>`, `keyring` — системное хранилище (Keychain / Credential Manager /
Secret Service).

Перескажи пользователю коротко, по строке на токен:

| Результат | Что сказать |
|---|---|
| `HTTP 200` | всё в порядке |
| `HTTP 401` / `HTTP 403` | токен неверный или отозван: перевыпустить в сервисе и выполнить `uvx keyring set qaily <имя>` |
| `не найден — …` | дать команду из строки вывода дословно |
| `не найден (необязательный)` | Context7 работает с урезанным лимитом, ключ можно добавить по желанию |
| `сеть: …` | сервис недоступен с этой машины: VPN, прокси, интернет |
| `uv: command not found` или похожее | не установлен uv — ссылка на раздел «Установка» в README |

После любых правок токенов — перезапустить сессию Claude, иначе MCP-серверы не перечитают
секреты.

Значения токенов у пользователя не запрашивай и не выводи; `uvx keyring set` пользователь
выполняет сам в своём терминале — команда спрашивает значение скрытым вводом.
