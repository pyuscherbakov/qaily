# Claude Code

Определи клиент по фактической среде и доступным инструментам. Используй доступные инструменты чтения файлов и изображений; PDF читай страницами, если это поддерживается. Вложения Redmine, недоступные sandbox, перечисляй как непроверенные; не обходи ограничения. URL загружай инструментом, позволяющим получить исходное содержимое без пересказа; если это невозможно, сообщи ограничение. Имена MCP и их возможности обнаруживай в текущем каталоге инструментов, а не предполагай по префиксу; не выдумывай недоступные вызовы.

Для делегирования используй доступный Agent tool и соответствующий Claude wrapper. Передавай абсолютный procedure_path в установленном пакете, эффективный projectId и только необходимые входы; агент сам читает процедуру. Если изолированное обязательное делегирование недоступно, сообщи ограничение и останови зависимый этап, не читай сырые стеки inline. Планируй очередь по фактическим слотам, не уменьшая охват и соблюдая лимиты процедуры.
