# Выбор проекта TestOps

Перед первым обращением к TestOps определи эффективный projectId: явный выбор пользователя имеет приоритет над ID проекта в ссылке на объект; если ни того, ни другого нет, используй 1 (FAST2 Автострахование). Если явный ID и ID в ссылке различаются, спроси пользователя до любых вызовов TestOps и дождись ответа. Голые ID кейса или запуска и URL запуска без проекта используют 1. Любой положительный ID, включая отсутствующий в справочнике, допустим; не проверяй другие проекты автоматически, даже если объект не найден. Сообщи выбранный проект при отсутствии объекта.

Справочник `projects.json` — снимок названий для отображения, а не список разрешённых ID и не проверка доступа. Перед записью покажи в таблице название и ID проекта; неизвестное название обозначь как неизвестное. Ссылки строй из эффективного URL сервиса и выбранного projectId: `<effective-url>/project/<projectId>/test-cases/<id>`. Утверждение таблицы и подтверждение каждого мутирующего вызова обязательны; если политика подтверждения не проверена, запись не начинай.
