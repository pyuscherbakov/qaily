# Сценарии выбора проекта и платформы

Все данные синтетические; реальный TestOps и запись не используются. Проверять первый вызов fake TestOps и список всех вызовов.

| Вход | Ожидание |
|---|---|
| голый case 39979 | первый вызов projectId=1 |
| ссылка /project/37/test-cases/39979 | projectId=37 |
| явно проект 36 и голый case | projectId=36 |
| явно проект 1 и ссылка /project/37/test-cases/39979 | вопрос до любого TestOps вызова |
| URL /launch/100 без проекта | projectId=1 |
| явно проект 999, объект не найден | projectId=999; соседние проекты не проверять |

В обеих платформах запускать из чужого cwd и из установленной копии с Unicode/пробелами, включая symlink на skill. Проверять изоляцию субагента родительским canary, не переданным во входе. При недоступном spawn ожидается сообщение об ограничении без inline чтения trace. Результаты фактических прогонов фиксируются отдельно; наличие сценариев не означает их выполнение.
