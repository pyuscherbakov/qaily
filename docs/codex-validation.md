# Приёмка Qaily 0.5.0

Матрица описывает фактические доказательства, а не обещание поддержки всех сред.
Автоматические тесты и синтетические MCP не подтверждают живой сервис, исполнение
политики или работу навыка в интерактивном клиенте. CI запускает Python 3.10 и 3.12
на трёх ОС; результаты конкретного запуска нужно смотреть в его журнале. На Python
3.10 тесты, требующие `tomllib`, пропускаются: это не полное покрытие policy.

| ОС / клиент | Поверхность и проверка | Результат | Доказательство |
|---|---|---|---|
| macOS / Codex CLI 0.166.0-alpha.5.1 | локальная установка и обнаружение пакета, шесть skills; fixture cache с Unicode и пробелами | синтетически проверено, версия не является минимумом | [Установка](codex-install.md); native fixture |
| macOS / тот же CLI | top-level HTTP с полным фиктивным заголовком, initialize/list/call | синтетический PASS; не live auth | локальный loopback MCP, ноль записей |

| macOS / тот же CLI | policy и делегирование | частично: отдельные fixture фильтрации и noninteractive approval; дочерние сценарии не завершены | native fixture; не доказано интерактивное применение |

| Все ОС / живые семь MCP, Jam OAuth, browser | чтение, авторизация и сеть | not_checked | отдельные внешние коннекторы не доказывают подключение пакета |
| Все ОС / live write | явный тестовый проект и подтверждение каждого вызова | not_checked | разрешение и тестовый проект не предоставлены |

Официальный TestOps `https://astbroker.qatools.cloud/api/mcp` остаётся включённым;
по данным пользователя он доступен только из РФ. Ошибка сети не доказывает ошибку
авторизации или policy. CI не делает живых запросов, и статус пропуска native и live
интеграции не является PASS. Запись запрещена до проверки фактической policy и
отдельного подтверждения. Проект 1 по умолчанию не разрешает создавать fixture.

## Критерии установки и обновления

Следующие acceptance cases остаются **not_checked**, пока не выполнены в изолированном
профиле с установленным пакетом и документированными версиями:

- Fresh private Git-marketplace install: обнаружить все шесть skills и семь MCP ID,
  проверить чтение ресурсов именно из установленного cache, а не из checkout.
- Update предыдущей версии: убедиться, что новые инструкции берутся из cache; сравнить
  снимки несекретной конфигурации, подтвердить сохранение JSON settings и постороннего
  Codex config. Факт `resolve_secret` проверять фиктивным значением без вывода токенов.
- Повторная установка: проверить по одному серверу каждого ID и отсутствие дубликатов;
  сохранение секретов проверить через успешное разрешение фиктивного секрета, не
  выгружая и не сравнивая реальные значения.
- Проверить холодный uv/npx, путь с Unicode, desktop PATH и restart после смены
  фиктивного токена. Прямая Git URL установка и update ещё не подтверждены.
- Выполнить все шесть workflow и policy cases на каждой заявляемой среде; отдельно
  проверить семь живых подключений и OAuth Jam. Доступ к live-сервисам и отдельное
  согласование записи не заменяются синтетическими тестами.
